What it accepts

KindFormatsHow it is read
DocumentsPDF, Word (.docx), text, MarkdownText extracted on upload (PDF pages with no text go to image reading)
SpreadsheetsExcel (.xlsx), CSVEach sheet's rows as text
ImagesPNG, JPG, WebPGemini reads the text and describes the image (fee schedules, flyers, office photos)

Limits proposed: 20 MB per file, 200 MB per firm. File type is checked from the file's contents, not its name.

Decided

  • Scope: one library per firm, shared by all of that firm's agents.
  • Reading happens once, at upload, on the dashboard server (it has the PDF, Word and Excel readers). The call worker only searches the stored text, so calls stay fast and the worker needs no new packages.
  • Stored in PostgreSQL next to the other app data, scoped by firm. Original files kept so they can be downloaded or re-read.
  • The current query_knowledge_base stub goes. It returns made-up shop answers (return policy, pricing plans) that an agent could repeat to a caller.
  • No match means no guess: the agent says it will have someone follow up, as the global rules already require.
