How to use this dashboard

← Back to Call Desk

Call Desk runs AI phone agents: a caller speaks, the agent listens, thinks with a language model, answers in a chosen voice, and afterwards the call is summarised, the important details are extracted and can be posted to your systems. This page walks through every screen in the order you will use them.

1. Sign in first run

Open the site and you land on Sign in. The very first visit asks you to create the admin sign-in: your email and a password of at least 8 characters.

  1. Email & password. Tick Keep me signed in for a 30-day session; otherwise it lasts 12 hours.
  2. SMS code (optional). If a phone number is saved on your profile, a 6-digit code is texted to it and must be entered before you are in. No phone means password alone signs you in.
  3. Sign out from the profile card at the bottom of the sidebar or from My Profile.
Twilio trial accounts can only text numbers verified in the Twilio console. Verify your mobile there (or upgrade) before adding a phone to your profile, or the code cannot be delivered.

2. Provider keys admin only

Open API Keys & Providers. Each card is one service; paste the key, press Save, and the status turns green when the key is accepted. Keys are stored in the server's .env file and are never shown to non-admins.

ProviderWhat it doesNeeded for
DeepgramSpeech-to-text, and the Aura voicesEvery live call
Google GeminiThe language model that writes the agent's replies and extracts dataReal conversations (without it a fixed script answers)
ElevenLabsPremium voicesOptional; premade voices work on the free plan
Twilio / TelnyxPhone numbers, SIP trunks, SMS sign-in codesPhone numbers and SMS
OpenAI, Cartesia, RetellAlternative models and voicesOptional
Free-tier limits. Gemini 3.5 Flash Lite is the default because it allows more requests per minute on the free tier; Gemini 3.6 Flash is smarter but limited to 5 per minute, which is too few for a live call.

3. Build an agent

Go to Agents on the Call Desk and press ＋ New agent, or Edit an existing one. The Agent Builder has everything an agent needs.

SettingWhat to put there
NameHow the agent appears in lists and call history.
System promptThe agent's instructions: who it is, what to ask, what never to say. The AI follows this on every turn.
First messageThe exact opening line. Keep it identical to the greeting your prompt mandates, otherwise the AI will say the greeting again.
Who speaks firstAI (the agent greets on pick-up) or the caller.
VoiceOpen the voice picker; see section 5.
ModelWhich language model answers. Gemini 3.5 Flash Lite is the safe default.
Function toolsActions the agent may take mid-call: check availability, book, look up an order, transfer the call.
Webhook & data extractionOptional. Turn it on to have the AI pull details out of every transcript and post them to your systems; see section 8.

Press Save changes. Every save keeps a revision, so you can roll back. Each user owns the agents they create; admins see all agents.

4. Test call

Press Test in the Agent Builder. A call window opens, the agent greets you, and you can type or speak through the microphone. Each reply shows three things:

⏱ 1.3s reply time for the model to answer🔊 0.5s voice time until you hear it🧠 gemini or 📜 rule script if no model key
  • The microphone pauses while the agent speaks so it never transcribes her own voice.
  • When the agent signs off ("Take care"), the call ends by itself.
  • On hang-up the call is saved to Call History with a recording made from exactly what you heard, plus your microphone if you used it.

5. Voices

Open the picker from the Voice card. Every voice shows a chip telling you what will actually speak:

  • ✅ ElevenLabs Turbo / Deepgram Aura / Neural HD — this exact voice plays in tests and on live calls.
  • ⚠️ Neural HD fallback — this voice cannot be synthesised here (no key, a paid-plan voice, or a sample-only Retell voice), so a free neural voice speaks instead. The reason is in the tooltip and in a warning when you pick it.

Tick Real voices only to hide the fallback ones. ↻ Sync accounts pulls in any voice you added to your ElevenLabs account. The fastest voices are ElevenLabs premade voices (about half a second to first sound); Deepgram Aura is about one second.

6. Go live & phone numbers

  1. Set live. On the Agents tab press 📞 Set live. The live agent answers any call that has no specific routing.
  2. Buy a number. Buy Phone Numbers lists Telnyx and Twilio inventory; buying assigns the number to a trunk and an agent.
  3. Route per number. On SIP Trunks & DIDs each owned number has an agent dropdown. Several agents can each answer their own number.
Real phone calls need a SIP gateway. The current stack does not run a LiveKit SIP service, so dialling from the softphone and inbound calls to your Twilio number are simulated. Talking to an agent in the browser (test call or softphone) is fully real.

7. Calls & recordings

The Overview shows counts, recent calls, sentiment and hourly volume. Calls is the full history with filters and search; click a row for Call detail: transcript, sentiment, summary, extracted fields, waveform and a playable recording (left channel caller, right channel agent). Export CSV downloads the filtered list. You see the calls handled by your own agents; admins see all.

8. Webhooks & extracted data

Two parts: what to extract (per agent) and where to send it (workspace endpoints).

  1. In the Agent Builder open Webhook & data extraction and switch Enable on.
  2. Press ✨ Suggest from prompt. The AI reads the agent's prompt and proposes fields (name, callback phone, email, matter…). Edit them, mark required ones, then Save changes.
  3. Press ▶ Preview on latest call to see what the AI pulls out of a real transcript.
  4. On Webhooks & Data add an endpoint URL and press Test; a green "Connected · HTTP 200" means your system received the signed test event.

After every call of an enabled agent your endpoint receives a JSON POST with call, extracted (flat key/value), summary, sentiment and transcript, signed with X-Signature-256 (HMAC-SHA256 of the body with your endpoint secret). Deliveries and retries are listed on the page with a Replay button.

9. Softphone

The Softphone page dials into the live agent through your browser: press the number, dial, allow the microphone, and the agent greets you. The log shows which voice engine is speaking and when the agent ends the call. It is the quickest way to hear the live configuration exactly as a caller would.

10. Users & roles admin

On My Profile an admin adds members with a name, email, optional phone (for the SMS step), a role and a temporary password they can change later.

RoleCan do
AdminEverything, including API keys and members; sees all agents and calls.
OperatorFull dashboard except API keys; sees and edits only the agents they created and those agents' calls; can set their own agent live.
AnalystSame visibility as operator, intended for read-only review.

11. Where the data lives

Agents, revisions, phone numbers, trunks, users, sessions, call jobs and every recording are written to PostgreSQL (the voice-postgres container) as well as to the working files on disk. If a file or recording goes missing it is restored from the database at the next start. The Data & storage panel on My Profile shows the connection and counts.
