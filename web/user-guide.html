This guide is for everyone who signs in to build and run AI phone agents. You get the whole dashboard — every agent in the workspace, all call history, webhooks — except the API Keys & Providers page and member management. Setup topics (keys, phone numbers for the workspace, adding users, storage) are in the Admin guide.

1. Sign in

  1. Open the site. Enter the email and temporary password your admin gave you.
  2. If a phone number is saved on your profile, a 6-digit code is texted to you. Type it in; it expires after 5 minutes and you can resend after 30 seconds.
  3. Tick Keep me signed in to stay signed in for 30 days; otherwise the session lasts 12 hours.

Sign out from the profile card at the bottom of the sidebar or from My Profile.

2. Your profile

Open My Profile to set your name, title, email and phone, and to change the temporary password (Security card). Adding a phone turns on the SMS code step for your sign-in. The Members card shows only you; admins manage the team.

3. Build an agent

Go to Agents and press New agent. If you have no agents yet the builder opens in "Create your first agent" mode: give it a name and a prompt and press Save changes. The agent belongs to you; other members cannot see it.

Every save keeps a revision so you can roll back. Use Edit on the Agents tab to reopen an agent later.

4. Writing the prompt

  • Identity first: who the agent is, which business, what it must never do (no legal or medical advice, no pricing promises).
  • One question per turn. Say it explicitly; the model follows it.
  • List the data to collect in order: name spelled letter by letter, callback number with country code, email, address, the matter itself. The webhook feature can read this list back out of the prompt.
  • Confirmations: tell the agent to read back names, numbers and emails before moving on.
  • Closing line: include a sign-off such as "Thank you, take care". The call ends automatically when the agent says it.
Tip: the first message field must contain the same greeting the prompt asks for. If they differ, the agent greets twice.

5. Choose a voice

Every voice in the picker shows a chip that tells you what will actually speak:

  • ElevenLabs Turbo / Deepgram Aura / Neural Voice — this exact voice plays in tests and live calls.
  • Neural Voice fallback — this voice cannot be synthesised with the workspace's current keys or plan, so a neural voice speaks instead. The reason is in the tooltip and in a warning when you pick it.

Tick Real voices only to hide fallback voices. ElevenLabs premade voices start speaking fastest (about half a second); Deepgram Aura takes about one second.

6. Test call

Press Test in the builder. The agent greets you; type or use the microphone. Each reply shows:

1.3s reply model thinking time0.5s voice time until you hear itgemini the model wrote it
  • The microphone pauses while the agent speaks so it never hears itself. Headphones give the cleanest result.
  • When the agent signs off, the call ends by itself and is saved to Calls with a recording of exactly what you heard.
  • If a reply says rule script, no language model is connected; ask your admin to add a Gemini key.

7. Set live & phone numbers

  1. On the Agents tab press Set live on your agent. The live agent answers any call without specific routing. Only one agent is live at a time.
  2. On SIP Trunks & DIDs each owned phone number has an agent dropdown. Assign a number to your agent and it answers that line regardless of which agent is live.
  3. Need a new number? Buy Phone Numbers shows the available inventory, or ask your admin.
Real phone calls reach the agent only once the admin has connected a SIP gateway. Until then, hear the live agent through the Softphone page or a test call.

8. Calls & recordings

Overview shows counts, recent calls, sentiment and hourly volume for your agents. Calls is the full list with filters and search. Click a call for Call detail: transcript, sentiment, summary, extracted fields, waveform and a playable recording (caller on the left channel, agent on the right). Export CSV downloads the filtered list.

9. Extracted data & webhook

Optional per agent. In the builder open Webhook & data extraction and switch Enable on.

  1. Press Suggest from prompt. The AI reads your prompt and proposes the fields to capture (name, callback phone, email, matter…). Edit them, tick the required ones, save.
  2. Press Preview on latest call to see what the AI pulls out of a real transcript.
  3. After every call, the fields are filled from the transcript and posted to the workspace's webhook endpoints (set up by an admin on Webhooks & Data) together with the summary and transcript.

With the toggle off, nothing is extracted or sent for that agent.

10. Softphone

Dial from your browser to hear the live agent exactly as a caller would: press the number, dial, allow the microphone. The log shows the voice engine in use and when the agent ends the call.
