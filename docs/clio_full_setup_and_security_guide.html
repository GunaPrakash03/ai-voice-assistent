Step 2: Obtain the Clio Grow Inbox API Token

To enable the Voice Agent to push new incoming leads automatically into Clio Grow:

  1. Log in to your Clio Grow dashboard (e.g., https://grow.clio.com/).
  2. Click on Settings in the left-hand navigation sidebar.
  3. Click on Integrations, then locate the Clio Grow Public API section.
  4. Copy your Inbox Lead Token (a secure Bearer token string).
  5. Open your project .env file in voice-agent-service/ and set: 
    CLIO_GROW_INBOX_TOKEN=your_inbox_token_here
CLIO_ENABLED=true

Step 3: (Optional) Set Up Clio Manage OAuth 2.0 (For Live Tool Calls)

If you want the agent to perform live mid-call conflict checks and calendar booking:

  1. Go to https://developers.clio.com/ > My Apps > Create New App.
  2. Set Application Name to Voice Agent Integration.
  3. Select Scopes: read_conflicts, write_calendar, read_contacts.
  4. Copy your Client ID and Client Secret into .env.

Key Security Certifications & Compliance Standards:

4. Where is the Data Stored? (Data Residency & Privacy Architecture)

A critical architectural question for legal and voice systems is: Where do recordings and transcripts live?

1. Clio Cloud Infrastructure & Regional Residency

Clio's cloud is hosted in tier-4 enterprise data centers managed by Amazon Web Services (AWS) across distinct legal jurisdictions:

  • United States: AWS US East (Northern Virginia) and AWS US West (Oregon).
  • Canada: AWS Canada Central (Montreal) — ensuring compliance with Canadian PIPEDA and provincial privacy acts.
  • Europe & UK: AWS Frankfurt and AWS London — ensuring strict adherence to EU GDPR and UK Data Protection Act 2018.

2. The Voice Agent Data Segregation Architecture

To optimize costs, maintain client confidentiality, and prevent cloud bloat, our integration implements a Zero-Audio-Bloat policy: 

[ Voice Call Inbound ]
          │
          ▼
[ Voice Agent Private Storage (Your Server / AWS S3) ]
  ├─ Raw Audio Recording (.wav, 16-bit stereo) ──► Stays in YOUR secure bucket
  ├─ PCI/PII Compliance Redaction (1400 Hz tone) ──► Never leaves your boundary
  └─ Audio Checksum (SHA-256) ──► Stored in your audit manifest
          │
          ▼ (Only structured text & presigned link sent via TLS 1.3)
[ Clio Grow / Manage Cloud Database ]
  ├─ Contact Details: First Name, Last Name, Phone, Email
  ├─ Case Categorization: Practice Area, Incident Date, Urgency Flag
  ├─ Text Summary: Executive transcript snippet
  └─ Audio Link: Expiring presigned link pointing to your private S3 bucket

6. How to Test (Step-by-Step Testing Protocol)

Level 1: Run the Automated Local Mock Test (No Credentials Needed)

Test the full serialization, payload transformation, and HTTP dispatch logic locally:

python3 scripts/test_clio_integration.py

Expected Output: SUCCESS: 3/3 Mock Integration Verification Checks Passed!

Level 2: Run a Live Dispatch Test with Your Clio Token

Send a real test lead into your Clio Grow Inbox:

python3 scripts/test_clio_integration.py --live --token=YOUR_CLIO_GROW_INBOX_TOKEN

Verification: Open your Clio Grow web interface > Inbox (or Lead Pipeline) > verify that Test Integration Caller appears in "New Inquiries".

Level 3: Conduct a Real End-to-End Voice Call Test

  1. Ensure your .env file has CLIO_GROW_INBOX_TOKEN configured.
  2. Open the browser softphone at http://localhost:8091/softphone.html.
  3. Join the room and speak: "Hello, my name is Eleanor Vance, my number is 555-019-2834, and I was injured in a car accident on September 15th."
  4. Hang up the call.
  5. The pipeline worker will mixdown audio, extract the legal fields, and push the lead directly to Clio Grow within 500ms.
